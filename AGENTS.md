# Repo guide for AI assistants

Read [CONTRIBUTING.md](CONTRIBUTING.md) before editing. Key rules:

- **Notebooks:** edit only `master_notebooks/*.py`; the root-level `NN_*.py` and
  `NN_*.ipynb` are generated by `./sync_notebooks.sh` and hand-edits are
  overwritten. See the "Authoring model" section for the full workflow.
- **Equations:** an equation has one canonical home (lecture notes); update the
  notes before changing implementation code.
